# 🌌 Echoes of the Cosmos

An interactive space exploration web experience built with React.js and JavaScript.

## ✨ About the Project

Echoes of the Cosmos is a 3rd-semester project focused on creating an immersive and visually engaging way to explore the cosmos through an interactive web experience.

The project combines space-themed visuals, interactive elements, animations, and educational content to make exploring the universe more engaging.

## 🚀 Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Git & GitHub
